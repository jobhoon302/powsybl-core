# PowSyBl network-viewer starter

Minimal starter project showing how to embed a PowSyBl **Network Area Diagram (NAD)**
in a plain TypeScript + [Vite](https://vite.dev/) app, using the React-free
[`@powsybl/network-viewer-core`](https://www.npmjs.com/package/@powsybl/network-viewer-core)
package from [powsybl/powsybl-network-viewer](https://github.com/powsybl/powsybl-network-viewer).

The viewer only *displays* an SVG and its metadata JSON: those two files are
produced by [powsybl-diagram](https://github.com/powsybl/powsybl-diagram) (or the
powsybl-core `NetworkAreaDiagram` API). A ready-made sample pair is bundled in
`src/data/` so the app renders immediately.

## Requirements

- [Node.js](https://nodejs.org/) 20.19+ or 22.12+
- npm (bundled with Node)

## Steps

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the dev server:

   ```bash
   npm run dev
   ```

   Open the printed URL (default http://localhost:5173) to see the diagram.

3. Build for production:

   ```bash
   npm run build
   npm run preview
   ```

## How it works

`src/main.ts` imports the sample SVG (as a raw string via Vite's `?raw`) and its
metadata JSON, then instantiates the viewer into a DOM container:

```ts
import { NetworkAreaDiagramViewer } from '@powsybl/network-viewer-core';
import svgContent from './data/nad-eurostag-tutorial-example1.svg?raw';
import metadata from './data/nad-eurostag-tutorial-example1_metadata.json';

new NetworkAreaDiagramViewer(
    document.getElementById('nad-container')!,
    svgContent,
    metadata,
    { enableDragInteraction: true, addButtons: true }
);
```

## Using your own diagram

Replace the two files in `src/data/` with an SVG + `*_metadata.json` pair
generated by powsybl-diagram / powsybl-core, and update the import paths in
`src/main.ts`. For example, with powsybl-core:

```java
var svgWriter = new StringWriter();
var metadataWriter = new StringWriter();
new NetworkAreaDiagram(network)
    .draw(svgWriter, metadataWriter, new SvgParameters(), new LayoutParameters());
```

## Other packages

- `@powsybl/network-viewer-core` — NAD + single-line diagram (SLD) viewers, no React (used here).
- `@powsybl/network-viewer` — full package, adds the map viewer; requires React / MUI peer dependencies.
- `@powsybl/network-map-layers` — deck.gl layers only.
